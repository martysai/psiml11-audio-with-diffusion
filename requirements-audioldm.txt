# src/audioseal_robust/attacks.py), which runs inference through the
# vendored src/audioldm_train/ package (see that directory's VENDORED.md).
# NOT needed for anything else in this project -- separate from
# requirements-training.txt so the base training/eval flow doesn't need this
# much heavier, diffusion-model-specific stack.

# src/audioldm_train/config/2023_08_23_reproduce_audioldm/audioldm_original.yaml
# until nothing was left unresolved -- not hand-picked from audioldm_train's
# own (nonexistent) requirements file, it ships none.

# taming-transformers is deliberately NOT listed. AutoencoderKL builds a
# training-time LPIPS perceptual loss in __init__ that would need it, but
# AudioLDMAttack._load_backbone swaps that lossconfig for a no-op before
# construction (we only ever call encode/decode, never train the VAE). That
# also avoids LPIPS downloading a ~500MB vgg.pth into a *relative* path,
# which fails outright when the weights dir is a read-only mount.
